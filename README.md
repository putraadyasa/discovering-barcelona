# Discovering Barcelona 🏙️

An exploratory data analysis of Barcelona's demographic landscape using Python and pandas.

## About This Project

This project analyzes open data from Barcelona across five key demographic dimensions:
population, immigration & emigration, births & deaths, life expectancy, unemployment, and names.

The dataset is sourced from [Kaggle - Barcelona Data Sets](https://www.kaggle.com/datasets/xvivancos/barcelona-data-sets) by Xavier Vivancos.

## What's Inside

| Phase | Topic |
|-------|-------|
| Phase 1 | Population by district and neighborhood |
| Phase 2 | Immigration & emigration flows |
| Phase 3 | Births, deaths, and natural growth |
| Phase 4 | Life expectancy by gender |
| Phase 5 | Unemployment trends & most frequent names |

## Methods & Tools

- **Python** (pandas, matplotlib, plotly, wordcloud)
- **Google Colab**
- Scaffolded learning approach — built independently with AI assistance (Claude)
- Inspired by Xavier Vivancos' original Barcelona analysis

## Key Visualizations

- Sankey diagram of migration flows
- Stacked bar charts for births vs deaths by district
- Gradient bar charts for unemployment by gender and month
- WordCloud of most frequent names in Barcelona (1996–2017)
